Immich Random Image
===================

Display random images from your Immich v3+ instance on your Home Assistant dashboards.

## Features

- Random image from your entire library, a single album, or multiple albums
- SSL verification toggle for self-signed certificates
- Works with localhost, private IPs, and domain names
- No external Python dependencies
- Configurable via UI (config flow + options flow)
- Optional setup name shared by all five entity defaults
- Configurable rotation (5 minutes by default), or interval 0 for manual-only refresh

## Installation

Install via HACS. Add this repository as a custom repository (category: Integration), then search for "Immich Random Image".
